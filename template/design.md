# 作品集设计规范

本文档基于当前作品集页面（`style.css`）整理，用于保持后续页面在配色、字体、间距和组件上的一致性。

整体风格：**深色底、高对比白字、珊瑚红点缀、大圆角、少边框、轻阴影、留白充足。**

字号换算以根字号 `16px` 为准。

---

## 1. 配色

| 角色 | Token | 色值 | 用途 |
| --- | --- | --- | --- |
| 主色 | `--accent` | `#ef5d78` | 强调点、编号圆点、标签文字、主按钮 |
| 辅助色 | `--tag-bg` | `#3a1f26` | 标签底、主色浅底、次要强调容器 |
| 辅助色 | `--card-hover` | `#1c2220` | 卡片悬停、次级抬升面 |
| 背景色 | `--bg` | `#0b0e0d` | 页面底色 |
| 背景色（抬升） | `--card` | `#161b19` | 卡片、导航栏、浮层底 |
| 文字色（主） | `--text` | `#f5f6f6` | 标题、卡片标题、导航文字 |
| 文字色（次） | `--muted` | `#8d9692` | 副标题、说明、辅助信息 |
| 反白文字 | — | `#ffffff` | 主按钮文字、编号圆点内数字 |
| 边框 | — | `rgba(255, 255, 255, 0.04)` | 卡片、导航栏细边框 |
| 阴影 | `--shadow` | `0 16px 36px rgba(0, 0, 0, 0.35)` | 卡片 / 下拉悬停 |

### 使用原则

- 页面大面积只用背景色 `#0b0e0d`，不要铺主色。
- 主色 `#ef5d78` 只用于点缀：标题上方圆点、编号、主按钮、标签文字。
- 正文不要用纯白 `#ffffff`，标题和正文用 `#f5f6f6`，说明用 `#8d9692`。
- 标签采用「深底 + 主色字」，不要做成实心主色块。

## 2. 字体

**字体栈：** `Inter, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`  
字重用量：`400` / `600` / `700` / `800`。开启 `-webkit-font-smoothing: antialiased`。

| 层级 | 场景 | 字号 | 字重 | 行高 | 字距 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- |
| Hero 标题 | 页头 `h1` | `3.55rem`（约 `56.8px`） | `800` | `1.12` | `-0.04em` | `#f5f6f6` |
| 分区标题 | Featured Works | `2rem`（`32px`） | `700` | 默认约 `1.2` | `-0.03em` | `#f5f6f6` |
| 卡片标题 | 作品名 `h3` | `1.12rem`（约 `18px`） | `700` | `1.3` | `-0.02em` | `#f5f6f6` |
| 正文 / 副标题 | 页头说明 | `1.02rem`（约 `16px`） | `400` | `1.75` | `0` | `#8d9692` |
| 卡片说明 | 作品简介 | `0.86rem`（约 `14px`） | `400` | `1.65` | `0` | `#8d9692` |
| 标签 / 次按钮 | `.tag` | `0.72rem`（约 `11.5px`） | `600` | `1.4` | `0.01em` | `#ef5d78` |
| 编号数字 | 卡片序号 | `0.7rem`（约 `11px`） | `700` | `22px` | `0` | `#ffffff` |
| 页面默认 | `body` | `16px` | `400` | `1.65` | `0` | `#f5f6f6` |

### 响应式字号

| 断点 | Hero 标题 | 分区标题 | 页头说明 |
| --- | --- | --- | --- |
| `≤ 960px` | `2.5rem`（`40px`） | `1.7rem`（约 `27px`） | `1.02rem` |
| `≤ 600px` | `2rem`（`32px`） | `1.7rem` | `0.95rem` |

标题层级对比：Hero（800）> 分区标题（700）> 卡片标题（700）> 正文（400）。标题偏紧行高、略收字距；正文偏松行高，保证呼吸感。

## 4. 组件样式

当前页没有独立导航栏，下列导航规则与现有深色卡片 / 胶囊标签同一套体系，便于以后扩展。

### 4.1 圆角

| 组件 | Token / 值 | 规则 |
| --- | --- | --- |
| 卡片 | `--radius-card: 26px` | 四角统一大圆角，内部截图随卡片裁切（`overflow: hidden`） |
| 主按钮 / 标签 / 次按钮 | `--radius-pill: 999px` | 全胶囊 |
| 编号圆点、页头点 | `50%` | 正圆 |
| 导航栏容器 | `16px`～`999px` | 悬浮条可用胶囊；贴顶栏可用 `0`（底边）或 `16px` |

### 4.2 边框

| 组件 | 规则 |
| --- | --- |
| 卡片 | `1px solid rgba(255, 255, 255, 0.04)`，几乎看不见，用来和背景轻轻分开 |
| 标签 | 无描边 |
| 主按钮 | 无描边，靠主色填充 |
| 次按钮 | 无描边，或 `1px solid rgba(255, 255, 255, 0.06)` |
| 导航栏 | 与卡片相同细白边，或无边框 |

不要使用粗描边或彩色描边作为默认态。

### 4.3 阴影

| 状态 | 值 |
| --- | --- |
| 默认（卡片 / 导航） | 无阴影（`box-shadow: none`） |
| 悬停（卡片 / 下拉） | `0 16px 36px rgba(0, 0, 0, 0.35)` |
| 悬停位移 | `translateY(-6px)` |
| 过渡 | `transform / background-color / box-shadow`，`0.28s ease` |

默认态保持扁平，只在交互时抬升。

### 4.4 按钮

**主按钮（对应页头强调、编号点）**

- 背景：`#ef5d78`
- 文字：`#ffffff`，`600`～`700`
- 圆角：`999px`
- 内边距：`10px 20px`
- 边框 / 默认阴影：无
- 悬停：略提亮或沿用卡片的 `translateY(-2px)`，不要加厚边框

**次按钮 / 标签（当前 `.tag`）**

- 背景：`#3a1f26`
- 文字：`#ef5d78`
- 字号：`0.72rem`，字重 `600`
- 圆角：`999px`
- 内边距：`5px 12px`
- 边框 / 阴影：无

### 4.5 卡片

- 背景：`#161b19`；悬停：`#1c2220`
- 圆角：`26px`
- 边框：`1px solid rgba(255, 255, 255, 0.04)`
- 默认无阴影；悬停阴影 + 上移 `6px`
- 最小高度（桌面）：`420px`
- 顶部截图高度：`210px`（手机 `190px`），`object-fit: cover`，从顶部对齐
- 截图底部用透明到卡片色的渐变（约自 `top: 70px`、高 `150px`）溶入内容区
- 标题左侧放 `22px` 主色编号圆点
- 说明文字用次要文字色，标签贴卡片底部（`margin-top: auto`）

### 4.6 导航栏

当前作品集为单页、无导航。若后续增加，按本规范处理：

- 背景：`#161b19`（与卡片一致），可加 `rgba(11, 14, 13, 0.85)` 毛玻璃
- 文字：默认 `#f5f6f6`，当前项或悬停用 `#ef5d78`
- 圆角：贴顶通栏为 `0`；悬浮导航为胶囊 `999px` 或 `16px`
- 边框：`1px solid rgba(255, 255, 255, 0.04)` 或无
- 阴影：静止无阴影；滚动吸附后可用卡片悬停阴影
- 高度 / 内边距：垂直 `12px～16px`，水平 `24px`，链接间距 `12px～20px`
- 导航内按钮沿用主按钮 / 次按钮规则
- 不要使用强投影、底部分割粗线或高对比描边
